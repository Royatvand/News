# توضیح مسیر داینامیک مقاله‌ها

در این بخش کاری کردیم که با کلیک روی هر مقاله در صفحه اصلی، صفحه جزئیات همان مقاله باز شود.

## هدف

نمی‌خواهیم برای هر مقاله یک صفحه جدا بسازیم. یک صفحه به نام `ArticleDetails` داریم و شناسه مقاله را از آدرس می‌خوانیم.

مثلاً:

- `/article/4863859` جزئیات مقاله با شناسه 4863859 را نشان می‌دهد.
- `/article/1234567` جزئیات مقاله با شناسه 1234567 را نشان می‌دهد.

## API مورد استفاده

برای دریافت مقاله‌ها از API عمومی DEV Community استفاده می‌کنیم:

- فهرست مقاله‌ها: `https://dev.to/api/articles?per_page=30`
- جزئیات یک مقاله: `https://dev.to/api/articles/ARTICLE_ID`

درخواست فهرست، آرایه‌ای از مقاله‌ها برمی‌گرداند. در درخواست جزئیات، علاوه بر اطلاعات اصلی، فیلدهای `body_html` و `body_markdown` برای محتوای کامل مقاله وجود دارند.

## چه فایل‌هایی را تغییر دادیم؟

### ۱. `src/App.jsx`

**کار این فایل:** مشخص کردن مسیرهای صفحات سایت.

**چه چیزهایی وارد کردیم؟**

- `Routes` و `Route` از `react-router-dom` برای تعریف مسیرها.
- کامپوننت `ArticleDetails` از فایل صفحه جزئیات.

مسیر داینامیک:

```jsx
<Route path="/article/:id" element={<ArticleDetails />} />
```

قسمت `:id` شناسه‌ای است که در آدرس تغییر می‌کند.

### ۲. `src/pages/articleDetails/articleDetails.jsx`

**کار این فایل:** دریافت و نمایش اطلاعات یک مقاله.

**چه چیزهایی وارد کردیم؟**

- `useParams` از `react-router-dom` برای خواندن شناسه از آدرس.
- `useState` و `useEffect` از `react` برای نگهداری اطلاعات و اجرای درخواست.
- `axios` برای دریافت اطلاعات از API.

**کارهایی که در این فایل انجام می‌دهیم:**

1. با `useParams` مقدار `id` را از آدرس می‌گیریم.
2. با `useState` یک State به نام `post` می‌سازیم و مقدار اولیه آن را `null` می‌گذاریم.
3. در `useEffect` با Axios درخواست مقاله را می‌فرستیم.
4. اطلاعات دریافتی از `res.data` را با `setPost` در State ذخیره می‌کنیم.
5. تا قبل از دریافت اطلاعات، پیام `Loading...` را نشان می‌دهیم.
6. بعد از دریافت اطلاعات، عنوان، توضیحات، نویسنده، تگ‌ها و متن کامل مقاله را نمایش می‌دهیم.

آدرس API برای هر مقاله:

```js
https://dev.to/api/articles/شناسه-مقاله
```

برای نمایش متن کامل مقاله از فیلد `body_html` استفاده می‌کنیم.

### ۳. `src/pages/home/home.jsx`

**کار این فایل:** دریافت فهرست مقاله‌ها و نمایش کارت‌ها در صفحه اصلی.

**چه چیزهایی وارد کردیم؟**

- `axios` برای درخواست به API.
- `useEffect` و `useState` از `react` برای دریافت و نگهداری فهرست مقاله‌ها.
- کامپوننت `ArticleCard` برای نمایش هر مقاله.
- کامپوننت‌های `Header` و `Footer` برای بخش‌های بالایی و پایینی صفحه.
- فایل استایل `home.module.css`.

درخواست فهرست مقاله‌ها به این آدرس ارسال می‌شود:

```js
https://dev.to/api/articles?per_page=30
```

پاسخ این endpoint یک آرایه است؛ بنابراین آن را مستقیماً با `setArticles(response.data)` در State ذخیره می‌کنیم.

### ۴. `src/Component/ArticleCard/ArticleCard.jsx`

**کار این فایل:** نمایش خلاصه هر مقاله و لینک رفتن به صفحه جزئیات آن.

اطلاعاتی که در کارت از API جدید استفاده می‌کنیم:

- `title`: عنوان مقاله
- `description`: خلاصه مقاله
- `user.name`: نام نویسنده
- `reading_time_minutes`: زمان تقریبی مطالعه
- `public_reactions_count`: تعداد واکنش‌ها
- `comments_count`: تعداد دیدگاه‌ها
- `tag_list`: تگ‌های مقاله

لینک هر کارت شناسه همان مقاله را داخل آدرس قرار می‌دهد:

```jsx
<Link to={`/article/${article.id}`}>
  Read More
</Link>
```

## نکته درباره BrowserRouter

در فایل `src/main.jsx` از قبل `BrowserRouter` را از `react-router-dom` وارد کرده بودیم و دور کامپوننت `App` قرار داده بودیم. بنابراین لازم نبود دوباره آن را در فایل‌های دیگر قرار دهیم.

## خلاصه مسیر اجرا

1. `Home` فهرست مقاله‌ها را از DEV.to دریافت می‌کند.
2. `ArticleCard` اطلاعات خلاصه هر مقاله را نمایش می‌دهد.
3. با کلیک روی `Read More`، لینک به مسیر دارای ID می‌رود.
4. `App.jsx` مسیر را به `ArticleDetails` وصل می‌کند.
5. `ArticleDetails` با `useParams` شناسه را می‌خواند.
6. با Axios اطلاعات همان مقاله را از DEV.to دریافت می‌کند.
7. اطلاعات در State ذخیره و متن کامل مقاله در صفحه نمایش داده می‌شود.
